# Règles du jeu — Le Cube Graphique

## 1. C’est quoi ce jeu ?
Bienvenue dans “Le cube graphique”, la plus prestigieuse agence de design du monde.
Vous venez d’y décrocher un stage de 2 mois… mais ici, les stagiaires sont en compétition permanente.

Votre objectif n’est pas seulement d’arriver le premier sur le plateau, mais de prouver que vous êtes le meilleur stagiaire en accumulant le plus de jalons.

Les actions du jeu se font en duo :
- un plateau physique (pions, cases, cartes),
- une application web sur téléphone qui gère les quiz, défis, activités et événements.

## 2. But du jeu
Le but du jeu :
- accumuler le plus de jalons,
- atteindre le bureau du Boss en premier.

À la fin de la partie, on compare les scores : celui qui a le plus de jalons remporte le stage de 2 mois.

## 3. Mise en place
1. Dépliez le plateau.
2. Choisissez votre pion et placez-le sur la case Départ.
3. Lancez l’application web sur un téléphone.
4. Choisissez qui commence.

## 4. Comment on joue ?
À votre tour :
1. Lancez le dé.
2. Avancez votre pion.
3. Dans l’application, indiquez la case sur laquelle vous êtes arrivé.

Selon la case, l’application vous proposera une action :
- **Quiz**
- **Défi**
- **Activité**
- **Bonus**
- **Événement**

### 4.1 Case Quiz
Les cases Quiz couvrent 6 grandes catégories de culture graphique :
- Culture graphique
- Signe et couleur
- Typographie
- Logo
- Composition
- Production

Quand vous tombez sur une case Quiz :
1. L’application tire un thème aléatoire parmi les 6 catégories.
2. Vous choisissez votre niveau de difficulté.
3. Vous répondez à la question.

Points gagnés pour une bonne réponse :
- Pour les nuls : 1 jalon
- Facile : 2 jalons
- Moyen : 3 jalons
- Difficile : 4 jalons
- Expert : 5 jalons

Si vous échouez, vous ne gagnez rien.

### 4.2 Case Défi
Quand vous tombez sur une case Défi :
1. Vous affrontez le joueur placé juste après vous dans l’ordre du tour.
2. L’application lance un défi entre vous deux.
3. Le défi peut être un quiz de rapidité, un vrai/faux, une estimation de chiffres, un jeu de couleur ou un challenge de reconnaissance de logo.

Types de défis possibles :
- **Buzzer** : on vous pose une question, le premier à buzzer et à répondre juste gagne.
- **Vrai/Faux** : les deux joueurs répondent, le premier bon gagne.
- **Chiffres** : chacun donne un nombre, le plus proche de la bonne réponse gagne.
- **Pick** : il faut choisir une couleur, celui dont la couleur est la plus proche de la cible gagne.
- **Zoom** : il faut reconnaître un logo, le premier à buzzer et à donner la bonne réponse gagne.

Règles générales du duel :
- Le vainqueur du défi remporte des jalons.
- En général, les défis rapportent 3 jalons.
- Pour le défi Zoom, le premier à répondre juste gagne 2 jalons.
- Si le premier joueur se trompe, l’adversaire remporte le défi et les jalons.

### 4.3 Case Activité
Certaines cases déclenchent une activité collective où tous les stagiaires jouent en même temps.

Quand l’activité est terminée :
- les stagiaires votent,
- la ou les meilleures réalisations remportent 2 jalons.

### 4.4 Case Bonus
Quand vous tombez sur une case Bonus :
- l’application vous attribue directement un bonus.
- vous découvrez son effet à l’écran.
- vous pouvez l’utiliser plus tard pour vous aider ou pour gêner un autre joueur.

Exemples de bonus possibles :
passer le tour d’un joueur ou relancer le dé

### 4.5 Case Événement
Quand vous tombez sur une case Événement :
- l’application déclenche directement l’événement.
- vous voyez son titre et son effet à l’écran.
- les événements peuvent changer le score, l’ordre de jeu ou offrir des avantages ponctuels.

Les événements s’appliquent immédiatement et disparaissent ensuite.
## 5. Ordre du jeu
L’ordre du tour est défini au début de la partie et reste le même, sauf indication contraire d’un événement ou d’un bonus.

Le joueur suivant est celui qui arrive après vous dans l’ordre du tour.

## 6. Fin de la partie
La partie se termine dès qu’un joueur arrive sur la case du bureau du Boss.

À ce moment :
- on arrête le jeu,
- on compte les jalons de tous les joueurs,
- celui qui a le plus de jalons remporte le stage de 2 mois.

## 7. Conseils pratiques
- Gérez bien vos bonus : ils sont souvent plus puissants lorsqu’ils sont utilisés au bon moment.
- Choisissez un niveau de quiz adapté : un niveau trop élevé peut coûter le point, un niveau trop bas limite les jalons.
- En défi, misez sur la rapidité, mais sans vous tromper.
- Restez attentif aux activités communes : elles offrent souvent une chance de rattraper le retard.

## 8. Résumé des points
- Quiz : 1 à 5 jalons selon la difficulté.
- Défi : 2 jalons pour le vainqueur.
- Activité : 2 jalons pour la ou les meilleures réalisations.
- Bonus : aide stratégique pouvant être jouée plus tard.
- Événement : effet spécial défini par l’application.

Bonne chance, futur stagiaire du Cube Graphique !
Que le meilleur gagne.
