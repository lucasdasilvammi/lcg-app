# Journal technique

Ce dossier garde les décisions techniques durables pour la refonte V1.

Le backlog produit reste hors du dépôt. L'utilisateur donne la tâche courante
directement dans les prompts. Ce journal sert uniquement aux décisions qui doivent
aider les futures sessions à comprendre pourquoi le code a évolué dans une certaine
direction.

Créer une note de décision quand une session change ou établit :

- une direction d'architecture ;
- un modèle de données ou contrat d'API ;
- un choix de dépendance ;
- une règle de déploiement ou d'environnement ;
- une stratégie de refactor majeure ;
- une convention de tests ;
- une convention de nommage ou de dossiers ;
- une décision de supprimer ou conserver un comportement hérité.

Les notes de décision vivent dans `docs/technical-journal/decisions/`.

Garder les entrées courtes, pratiques et faciles à relire plus tard.
