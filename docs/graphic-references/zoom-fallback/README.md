# Logos Zoom historiques

Ces trois PNG haute définition ont servi au premier contenu de test du défi
Zoom. Ils sont conservés comme références graphiques, mais ne doivent pas être
publiés avec le client.

Le fallback Starbucks de `server/data/duels.json` utilise désormais l'image
du catalogue actif : `client/public/defis/zoom/starbucks.jpg`.
