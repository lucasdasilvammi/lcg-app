# Instructions de remplacement des questions

## Objectif

Ce document constitue la source de vérité pour la prochaine mise à jour des
questions du jeu.

Il faut **supprimer toutes les questions actuellement présentes** dans les
fichiers ou listes correspondant aux défis suivants :

- `buzzer`
- `vraioufaux`
- `chiffres`

Après suppression, il faut **remplacer intégralement** leur contenu par les
questions listées dans ce document.

Ne pas conserver d'ancienne question non mentionnée ci-dessous. Les autres
types de défis, notamment `zoom`, ne sont pas concernés par cette instruction
et ne doivent pas être modifiés.

## Règles d'intégration

- Un défi Buzzer contient une bonne réponse et exactement deux mauvaises
  réponses.
- Un défi Vrai ou Faux contient les choix `Vrai` et `Faux`.
- Un défi Chiffres attend uniquement une réponse numérique.
- Chaque question doit conserver son explication.
- Les formulations, accents et signes de ponctuation doivent être conservés.
- Les questions Chiffres utilisent un entier, sauf le nombre d'or qui doit être
  affiché comme `1,618`.

## Défis Buzzer

Remplacer toute la liste actuelle par ces **4 questions**.

### 1. Qu'est-ce que le gris typographique ?

- Bonne réponse : Un concept qui englobe plusieurs éléments définis pour donner
  un bon équilibre à une composition.
- Mauvaise réponse : L'équilibre d'opacité entre noir et gris pour hiérarchiser
  les informations.
- Mauvaise réponse : La répartition du texte et des images pour créer un
  contraste visuel.
- Explication : Le gris typographique désigne l'équilibre visuel créé par la
  densité du texte sur une page.

### 2. Quelle est la couleur complémentaire du rouge ?

- Bonne réponse : Le vert.
- Mauvaise réponse : Le jaune.
- Mauvaise réponse : Le violet.
- Explication : Dans le cercle chromatique, les couleurs complémentaires sont
  placées à l'opposé l'une de l'autre.

### 3. Quel raccourci clavier permet de tout sélectionner ?

- Bonne réponse : Ctrl + A (Cmd + A).
- Mauvaise réponse : Ctrl + C (Cmd + C).
- Mauvaise réponse : Ctrl + Z (Cmd + Z).
- Explication : Ce raccourci universel fonctionne dans la plupart des
  logiciels.

### 4. Qu'est-ce qu'une typographie serif ?

- Bonne réponse : Une typographie avec empattements.
- Mauvaise réponse : Une typographie uniquement en capitales.
- Mauvaise réponse : Une typographie sans contraste de pleins et déliés.
- Explication : Une typographie serif possède des empattements aux extrémités
  des lettres.

## Défis Vrai ou Faux

Remplacer toute la liste actuelle par ces **8 affirmations**.

### 1. Le RGB est un modèle de couleur additif utilisé principalement pour les écrans.

- Réponse : Vrai.
- Explication : Le RGB, ou RVB, combine des lumières rouge, verte et bleue.

### 2. Le CMJN est un mode colorimétrique généralement destiné à l'impression.

- Réponse : Vrai.
- Explication : Le CMJN correspond aux encres cyan, magenta, jaune et noir
  utilisées en impression.

### 3. Le fond perdu sert à éviter un liseré blanc après la coupe d'un document imprimé.

- Réponse : Vrai.
- Explication : Le fond perdu prolonge les éléments graphiques au-delà du format
  final pour sécuriser la découpe.

### 4. Le crénage désigne l'ajustement de l'espace entre deux lettres précises.

- Réponse : Vrai.
- Explication : Le crénage agit sur une paire de lettres, contrairement à
  l'interlettrage qui concerne un ensemble plus large.

### 5. La loi de proximité de Gestalt indique que des éléments proches sont perçus comme liés.

- Réponse : Vrai.
- Explication : La proximité conduit le regard à regrouper les éléments situés
  près les uns des autres.

### 6. Une image destinée à l'impression est souvent préparée autour de 300 DPI.

- Réponse : Vrai.
- Explication : Une résolution de 300 DPI est une référence courante pour une
  impression de qualité.

### 7. Un logo pérenne est un logo qui suit toujours la dernière tendance graphique.

- Réponse : Faux.
- Explication : Un logo pérenne doit pouvoir durer au-delà des tendances
  graphiques passagères.

### 8. Deux couleurs complémentaires sont placées côte à côte sur le cercle chromatique.

- Réponse : Faux.
- Explication : Deux couleurs complémentaires se trouvent à l'opposé l'une de
  l'autre sur le cercle chromatique.

## Défis Chiffres

Remplacer toute la liste actuelle par ces **6 questions** : la question
conservée sur le nombre d'or et les cinq nouvelles questions proposées.

### 1. Donnez la valeur précise du nombre d'or.

- Réponse affichée : `1,618`
- Valeur technique : `1618`
- Nombre de chiffres : `4`
- Position de la virgule : `1`
- Explication : Le nombre d'or, aussi appelé phi, vaut environ 1,618.
- Source : *Le design graphique — savoirs & savoir-faire*, page 80.

### 2. En quelle année la typographie Futura a-t-elle été créée ?

- Réponse : `1927`
- Nombre de chiffres : `4`
- Explication : Paul Renner a créé Futura en 1927.
- Source : *Le design graphique — savoirs & savoir-faire*, page 68.

### 3. En quelle année la typographie Helvetica a-t-elle été créée ?

- Réponse : `1957`
- Nombre de chiffres : `4`
- Explication : Max Miedinger a créé Neue Haas Grotesk, ensuite renommée
  Helvetica, en 1957.
- Source : *Le design graphique — savoirs & savoir-faire*, page 69.

### 4. Combien de couleurs le cercle chromatique présenté dans le livre contient-il au total ?

- Réponse : `12`
- Nombre de chiffres : `2`
- Explication : Il contient 3 couleurs primaires, 3 secondaires et 6
  tertiaires, soit 12 couleurs.
- Source : *Le design graphique — savoirs & savoir-faire*, page 32.

### 5. Combien de bits composent un octet ?

- Réponse : `8`
- Nombre de chiffres : `1`
- Explication : Un octet est composé de 8 bits.
- Source : *Le design graphique — savoirs & savoir-faire*, page 92.

### 6. Combien de grandes phases composent la chaîne graphique présentée dans le livre ?

- Réponse : `5`
- Nombre de chiffres : `1`
- Explication : Les cinq phases sont la stratégie, la création, la réalisation,
  la finition, puis la distribution et la diffusion.
- Source : *Le design graphique — savoirs & savoir-faire*, page 22.
