# Client LCG

Client React/Vite du Cube Graphique. Les commandes courantes sont lancées
depuis la racine du dépôt (`npm run dev`, `npm run lint`, `npm run build`).

Installation isolée du client :

```sh
npm ci
```

Commandes disponibles dans ce dossier :

```sh
npm run dev
npm run lint
npm run build
```

Le build Vite est configuré pour produire `../build/`. Pour une compilation de
contrôle sans toucher à ce dossier suivi, fournir un `--outDir` temporaire.
